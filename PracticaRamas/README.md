# Práctica de ramas en GitHub

## Objetivo
Practicar la creación y publicación de ramas, registrar cambios mediante commits e integrarlos en la rama main.

## Archivos de la práctica

| Rama | Archivo |
| --- | --- |
| feature | README.md |
| bugfix | DocumentacionSolucion.txt |
| hotfix | DocumentacionSolucionhotfix.txt |

Los archivos de esta práctica se guardan en la carpeta PracticaRamas.

## Rama feature
Este README.md se crea en la rama feature para describir la práctica.
